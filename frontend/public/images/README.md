# FARMIS image assets

Files placed in this folder are served at `/images/...` by the app.
The UI currently ships with built-in placeholders — drop in the real
files with these exact names to replace them automatically:

| File               | Where it is used                                |
| ------------------ | ----------------------------------------------- |
| `promo-farm.jpg`   | Dashboard promo card background (wide farm photo) |
| `logo.png`         | ✅ **uploaded** — FARMIS mark (auto-generated from `images/logo.jpg`, cropped + transparent) |
| `avatar.png`       | Signed-in user avatar (initials until then)      |

`favicon.ico` in this folder was also generated from the logo
(16/32/48/256 px).
